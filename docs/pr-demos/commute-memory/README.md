# Horario recordado: demostración local

Las capturas y el video muestran Te Jalo real en 1280 × 800. El flujo usa registro, ingreso a comunidad y onboarding reales contra una base PGlite local con datos ficticios. No se simularon peticiones en el navegador.

Atomic Memory se sustituye por un **fixture HTTP local**, no el servicio en vivo. El video de 22 segundos muestra guardar 6:45–7:30, recargar para recuperar, olvidar desde Perfil y volver al horario inicial.

`screenshot.png` muestra la recuperación en Buscar y `perfil.png` permite ver y olvidar el horario. Se ocultó el indicador de desarrollo de Next en las capturas; en el video se cubrió únicamente su esquina con el fondo de la barra lateral. El contenido de la app no fue alterado.
